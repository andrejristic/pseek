# PSEEK — Install on macOS (.app)

## Build (once, on macOS) or use the provided PSEEK.app
```bash
pip3 install pyinstaller PySide6
pyinstaller --noconfirm packaging/pseek.spec
# output: dist/PSEEK.app
```

## Run
Open **PSEEK.app**. The first time, right-click → *Open* to bypass Gatekeeper for
an unsigned app (or allow it in System Settings → Privacy & Security).

## First run
