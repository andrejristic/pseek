# PSEEK — Install on Linux (.deb)

## Install
```bash
sudo dpkg -i pseek_0.1.0_all.deb
sudo apt-get -f install     # pulls python3 + pip if needed
```
The package installs to `/opt/pseek` and adds a `pseek` command + a desktop entry.
On first install it also runs `pip install PySide6`.

## Run
Launch **PSEEK** from your apps menu, or:
```bash
pseek
```
