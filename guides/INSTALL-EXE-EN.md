# PSEEK — Install on Windows (.exe)

## Build (once, on Windows) or use the provided pseek.exe
If you received `pseek.exe`, just double-click it. To build it yourself:
```bat
pip install pyinstaller PySide6
pyinstaller --noconfirm packaging\pseek.spec
REM output: dist\pseek.exe
```

## Run
Double-click **pseek.exe** (or run it from a terminal).

## First run
24h trial → $4.95 / $9.95 tiers · add your résumés/cover letters · connect your
email (`CONNECT-EMAIL-EN.md`). Windows SmartScreen may ask to confirm an unsigned
app the first time.
