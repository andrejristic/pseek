# PSEEK — Instalacija na Windows (.exe)

## Build (jednom, na Windowsu) ili koristi gotov pseek.exe
Ako si dobio `pseek.exe`, samo dvoklik. Da ga sam napraviš:
```bat
pip install pyinstaller PySide6
pyinstaller --noconfirm packaging\pseek.spec
REM izlaz: dist\pseek.exe
```

## Pokretanje
Dvoklik na **pseek.exe** (ili pokreni iz terminala).
