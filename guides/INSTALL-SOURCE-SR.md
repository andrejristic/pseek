# PSEEK — Pokretanje iz izvora (PySide6)

Za razvijaoce / napredne korisnike. Pokreće app direktno iz koda.

## Instalacija
```bash
cd PSEEK
pip install PySide6
```
Sve ostalo je čist standardni Python.

## Pokretanje
```bash
python3 run_pseek.py                # otvara aplikaciju
python3 run_pseek.py --selfcheck    # provjera bez GUI-ja
```

## Prvo pokretanje

toolbar **A− / A+** = veličina fonta (default 20) · **◐ tema** = svijetla/tamna.
