# PSEEK — Instalacija na Linux (.deb)

## Instalacija
```bash
sudo dpkg -i pseek_0.1.0_all.deb
sudo apt-get -f install     # povuče python3 + pip ako treba
```
Paket se instalira u `/opt/pseek` i dodaje komandu `pseek` + stavku u meniju.
Pri prvoj instalaciji pokreće i `pip install PySide6`.

## Pokretanje
Pokreni **PSEEK** iz menija aplikacija, ili:
```bash
pseek
```
