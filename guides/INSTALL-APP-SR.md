# PSEEK — Instalacija na macOS (.app)

## Build (jednom, na macOS-u) ili koristi gotov PSEEK.app
```bash
pip3 install pyinstaller PySide6
pyinstaller --noconfirm packaging/pseek.spec
# izlaz: dist/PSEEK.app
```

## Pokretanje
Otvori **PSEEK.app**. Prvi put desni klik → *Open* da zaobiđeš Gatekeeper za
nepotpisanu aplikaciju (ili dozvoli u System Settings → Privacy & Security).
