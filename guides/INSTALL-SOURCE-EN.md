# PSEEK — Run from source (PySide6)

For developers / advanced users. Runs the app directly from the code.

## Install
```bash
cd PSEEK
pip install PySide6
```
Everything else is pure standard library.

## Run
```bash
python3 run_pseek.py                # opens the app
python3 run_pseek.py --selfcheck    # headless status check
```

## First run
- First 24 hours: **everything unlocked** (trial). After that a paywall appears:
  **$4.95/mo** (1 résumé + 1 cover) or **$9.95/mo** (Combination Engine + multi-upload).
- Add your résumés and cover letters (or generate them in Chat).
- **Connect your email** to apply — see `CONNECT-EMAIL-EN.md`.
- (Optional) free LLM keys make chat richer; without them it runs on the local floor.

## Controls
Left sidebar = navigation · right panel = chat (drive everything by talking) ·
toolbar **A− / A+** = font size (default 20) · **◐ tema** = light/dark.
